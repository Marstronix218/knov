Chrome companion settings

This extension reads only the active tab URL and title. It never reads page contents, form input, or keystrokes.

Local app connection

Native Messaging is the secure default. Copy the pairing token shown by the Knoveyla Mac app to authorize this Chrome profile.

Excluded websites

One domain per line. A rule such as example.com also excludes its subdomains. Matching pages are stopped immediately and never queued.

What leaves Chrome

URL, page title, focus start time, and duration are sent to the paired Knoveyla app through Chrome Native Messaging. The extension contains no content scripts and cannot inspect the page body.
